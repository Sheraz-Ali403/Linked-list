# Linked-list
A from-scratch C++ implementation of common linked-list data structures, exploring pointers, dynamic memory management, templates, insertion/deletion, traversal, and time complexity.

## Project Structure

```text
LinkedLists/
│

│

│   └── main.cpp
│
├── doubly/

│   └── main.cpp
│
├── circular-singly/
│   ├── CircularSinglyLinkedList.h
│   └── main.cpp
│
└── circular-doubly/
    ├── CircularDoublyLinkedList.h

```
